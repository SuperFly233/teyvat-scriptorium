# 旅行历程与目录筛选设计

## 信息层级

目录卡片优先回答玩家最关心的四件事：任务类型、国家、章幕、Chapter 数量。魔神任务额外按“第几章”归组，并显示当前目录已经收录几幕；版本号和内部 ID 保留为较弱的检索信息。

筛选与排序分开。任务类型、国家、版本均为可叠加的多选条件；排序只改变结果次序，固定在结果统计右侧。重置按钮仅在存在筛选条件时出现。

## 旅行历程

时间线使用横向主干承载版本，国家首发节点扩大；魔神任务附着在主干，传说任务形成角色支线，世界与活动任务折叠为版本簇，防止一次铺开数百条记录。邀约事件先作为独立图鉴显示已收录数量，在版本元数据补全前不伪造发布日期。

桌面和手机都允许水平滚动。卡片模式与旅行历程模式共享同一份数据和打开任务行为，避免出现互相冲突的第二套目录。

## 数据边界

主目录沿用 Yatta 快照与后台更新；邀约事件暂从 Honey Hunter 的独立目录导入，并保留来源链接。页面明确标注当前可检索数量和“版本日期待补全”，不会把目录快照宣称为完整官方资料。
