# 多选与多段复制 · v0.10.2

已有非连续选句与工具栏批量复制，但入口在阅读顶部，滚动后难找。本轮在固定选句条增加“复制这些文本”和格式菜单。未选择时禁用；复制使用当前任务全部已选台词，按剧情顺序输出，不按点击顺序。计数包含筛选外选择并明确提示，清空取消全部选择；选稿仍沿用现有可见结果范围。

复制设置单列“多段复制”，每条台词视作一段。逐段对照与按语言分组共用现有格式器，段落分隔支持换行、空行、空格和自定义文本；语言顺序、独立名字格式、旁白等逻辑继续适用。设置中的预览从全部场景取前两条台词，避免首场景仅有一条时看不到间隔。

桌面操作条可换行，手机使用两行网格，让复制、格式菜单、清空及选稿都保持可见。验证非连续选句、逆序点击后的输出顺序、按语言分组、自定义间隔、全局设置入口、手机按钮可见性、原有打印与栏宽回归。继续保留两份本地数据修改，发布包使用 Git 已提交快照。
