# 目录语义与旅行历程导航设计

## 目录语义

传说任务和邀约事件的卡片不再只突出任务标题。卡片增加一条人物章幕信息：角色名作为主标识，旁边显示“某某之章·第几幕”或“邀约事件·某角色·第几幕”。版本、国家、内部 ID 和 Chapter 数量保持为次级信息。邀约事件继续使用同一套内部阅读器，通过 Yatta 的章节接口按需读取正文，不再默认跳往外站。

筛选器与排序器共用同一种自绘弹层。任意时刻只打开一个弹层；打开新弹层、点击空白区域或按 Escape 都会关闭旧弹层。无筛选时不渲染数值表达式，避免 React 将逻辑判断中的数字 `0` 显示到页面。

## 旅行历程

旅行历程提供“按版本”和“按国家”两种组织方式。按版本时，版本从早到晚；同一版本内按国家固定顺序排列，再按章号、幕号从小到大。按国家时，国家从蒙德、璃月一路排到至冬，内部仍按版本、章、幕排序。

每个国家组可以动画收起与展开。魔神、传说、邀约、世界和活动任务都提供真实可点击条目；数量只作为摘要，不再代替内容。数量很多的类别默认使用可展开的任务簇，避免页面失控。

## 横向定位

正文轨道上方增加同步导航轨：它与正文共享横向位置，并在国家首发节点显示国家名。底部增加时间轴缩略拖杆，只负责快速定位，不混入缩放。右下角“最新版本”按钮直接移动到轨道末端。正文滚动、顶部轨道滚动和底部拖杆三者双向同步，手机仍可自然触摸滑动。

## 验证

自动测试覆盖弹层互斥与点击空白关闭、无孤立 `0`、传说/邀约人物章幕、邀约进入内部阅读器、时间线两种组织方式、国家折叠动画、世界/活动任务可点击、上下轨同步、拖杆和最新定位。视觉检查覆盖 1440×900、390×844 和横向滚动后的状态。
