# 原神中外文剧情阅读器设计

## 目标

以官方本地化文本的稳定内部 ID 为轴，将同一任务、步骤与台词的中文和英文精确对齐。用户可以按任务与场景选取内容，以双栏、上下对照、单语和紧凑剧本等方式阅读，并可靠打印为 A4 文档。

## 数据架构

Project Amber / Yatta 的多语言 JSON 接口作为主数据源，Honey Hunter 页面作为人工核验与备用适配器。构建前运行采集脚本，将指定主线章节的 CHS、EN 数据下载、清洗并合并成一个版本化静态快照。对齐键依次使用章节 ID、任务 ID、步骤 ID、任务序号、对话节点 ID 与文本序号，不使用文本相似度。站点只读取快照，不在访客浏览时代理第三方网站，因此 Pages 上响应稳定、可离线缓存，也不会因跨域或源站限流破坏阅读和打印。

## 交互与版式

视觉方向是“北国档案馆里的旅行剧本”：墨绿、旧纸白和朱砂红，衬线字体，带页码与档案标记。左侧选择四个任务，正文顶部切换双栏、上下、中文、英文和紧凑模式；场景可以逐项勾选，搜索可同时匹配说话人和台词。打印面板提供 A4 双栏、对照讲义、中文剧本和英文剧本四种预设。打印样式取消滚动、粘性定位、阴影和交互控件，以 `break-inside: avoid` 保持单条台词完整，同时允许长场景跨页。

## 错误与验证

数据采集会检查两种语言的任务、步骤、节点和文本计数；缺失的一侧保留空白并标记，不让错位向后传播。应用提供加载失败状态。测试覆盖文本标记清洗、搜索和选择逻辑；构建后在桌面、移动端、滚动状态与打印媒体下做截图和溢出检查。
