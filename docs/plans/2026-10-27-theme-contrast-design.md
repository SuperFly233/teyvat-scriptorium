# 深浅主题交互控件对比度

问题来自强调色用途混用：`--red` / `--green` 既是纸张上的强调文字，也是填充按钮背景。深色主题将强调色调亮，但部分填充控件仍固定白字。增加对应的 `--on-red` / `--on-green`，按主题定义前景色，替换全站同类按钮、图标、勾选标记及提示的固定白字；固定深色导航和旅行历程背景保留配套浅色文字。

同时修复可读性相关问题：次要文字颜色、过低透明度的可用操作、未定义的打印密度背景、旅行历程计数和手机数量徽标。打印纸张颜色单独保留。

自动审核覆盖深浅主题、系统自动切换、桌面/手机、滚动、选中、悬停、焦点、复制处理中及禁用状态。真实浏览器扫描可见控件，并暂时隐藏文字和图标，从实际渲染截图采样背景，支持渐变和透明浮层。等待字体和动画稳定，排除被裁切或遮挡的元素。文字阈值为 4.5:1，纯图标为 3:1；禁用状态单独记录并审阅截图。

将审核要求写入 AGENTS.md、界面审核 SOP 和发布命令，后续界面变更必须扩展覆盖并运行审核，不再依赖用户截图提醒。保留两份已有数据改动，发布使用已提交的数据快照。
