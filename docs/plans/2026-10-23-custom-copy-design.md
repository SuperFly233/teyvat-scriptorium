# 可定制复制 · v0.10.0

沿用阅读与打印框架。每句提供按当前复制格式直接复制、展开格式选项，以及每个语言单独复制。章节信息、任务标题、引入、场景标题和引入文本提供相同入口；阅读工具支持复制当前筛选结果及当前任务已选台词。

设置与行内选项共用自动保存的偏好：语言跟随阅读或独立选择并排序；是否带角色名；名字与正文分隔（冒号、空格、换行、空一行、自定义）；语言与句子分隔；逐句或按语言分组；标注语言代码；保留段内换行。统一实时预览与纯文本生成，去除游戏控制标记并处理旅行者称谓，跳过缺失翻译与空名字。只使用已载入语言，避免错误语言回退。

阅读语言选择器增设上移、下移按钮，可让中文位于上下、左右任意位置。复制默认跟随这个顺序，也能独立调整。剪贴板被拒绝或不可用时打开可选中的手动复制文本，保持正文选句不受操作影响。全部复制控件隐藏于打印。

相较只增加一个整行复制按钮，统一复制器能覆盖单语、双语、多句与标题等需求；相较模板脚本或独立配置页，预设加自定义分隔符和实时预览更易操作。

验证：格式、缺失语言、顺序、旁白和旅行者变体单元测试；浏览器剪贴板真实内容、偏好持久化、阅读顺序、标题与引入、多句选稿、拒绝权限回退；1440×900 与 390×844 的滚动截图；已有阅读与打印回归。部署使用提交的数据，保留原有两份本地快照修改。
