# 复制稿日期与来源 · v0.12.0

日期与来源是整份复制稿的题头，位于全部语言正文前，仅生成一次。默认复制保留已有设置；Word 分语言稿预设开启题头。日期取复制当刻的本地日历日期，或用户指定的日期，输出不补零的年月日。

自动来源取当前章节、当前任务及目录元数据。完整格式组合《原神》、版本、地区、任务类型、章幕、章节与子任务；简短格式保留幕次与章节/任务。缺失字段省略，相同章节与任务标题只输出一次。允许编辑为固定自定义来源，并明确不会随任务切换。

题头加粗和题头后间隔独立设置，与已有段落及语言分隔互不干扰。标题、场景与引入的快捷复制不附加题头。HTML 与纯文本使用同一内容，HTML 安全转义。现有用户配置兼容迁移。

验证：日期合法性、格式示例、缺失元数据、重复标题、题头仅一次、空选句、HTML 转义、设置持久化；真实浏览器检查剪贴板双格式、原生富文本粘贴加粗、切换任务、桌面/手机与滚动状态。发布时仅使用已提交的剧情数据快照，保留本地两份数据修改。
