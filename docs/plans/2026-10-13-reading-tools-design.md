# 阅读资料与语言练习 · v0.9.0

延续现有逐句多语言对照、分支图、选稿、矢量打印及 Pages 部署。保留现有两份未提交数据快照。

本轮采用轻量阅读工具，不重做目录或打印：逐句收藏；独立笔记编辑；自动记录最近阅读台词并从目录继续；任意当前语言遮译与逐句揭晓；含 chapter、quest、line 的准确分享；按当前筛选或当前任务已选台词导出 Markdown / TSV。阅读资料支持 JSON 备份、严格校验、合并导入与标签页同步，原有笔记优先。

备选方案为重建独立学习工作区或加入账户同步，两者增加操作层级与维护成本，本轮暂不采用。资料存放浏览器，不依赖新服务；存储不可用时保持页面可读并提示备份。导出使用现有语言及旅行者称谓，打印继续使用原独立文档，不携带收藏按钮或遮译状态。

复盘修复：存储异常不应打断设置与正文加载；并发请求以最新请求为准，返回目录应中止请求；切换语言不应清空搜索及选句；选句状态下子按钮键盘事件不应触发行选择；搜索高亮与忽略空白的匹配规则一致。

验证：备份及多语言导出单元测试；浏览器真实收藏、笔记持久化、遮译、分享定位、导出下载、备份恢复、继续阅读；桌面 1440×900、手机 390×844、滚动与深色检查；原有分支、栏宽、导航、打印回归。完成后同步源码并部署 Pages。
